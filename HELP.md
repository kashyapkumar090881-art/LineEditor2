# Simple Line Editor - Help

## 1. Insert Line

Inserts a new line at the specified line number.

### Usage

Select:

```text
1. Insert Line
```

Then enter the line number and text.

### Example

```text
Enter line number to insert: 2
Enter text: Hello World
```

---

## 2. Delete Line

Deletes the line at the specified line number.

### Usage

Select:

```text
2. Delete Line
```

### Example

```text
Enter line number to delete: 2
```

---

## 3. Display Document

Displays all lines currently stored in the document with their line numbers.

### Usage

Select:

```text
3. Display Document
```

### Example

```text
1: Hello
2: Welcome
3: Line Editor
```

---

## 4. Save Document

Saves the current document into `document.txt`.

### Usage

Select:

```text
4. Save Document
```

---

## 5. Load Document

Loads the document from `document.txt`.

### Usage

Select:

```text
5. Load Document
```

---

## 6. Exit

Closes the line editor.

### Usage

Select:

```text
6. Exit
```
